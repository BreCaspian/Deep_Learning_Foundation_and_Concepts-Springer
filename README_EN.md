## 🗂️ Repository Structure

The repository is organized as follows:

- **Book/** — Book-related materials
  - **Book_PDF/** — PDF version of the book
  - **Book_PNG/** — PNG versions of book pages

- **Code/** — Code examples and exercise notebooks
  - Includes Jupyter notebooks covering handwritten digit recognition, PyTorch fundamentals, neural network implementations, and the U-Net architecture

- **Data/** — Datasets used for exercises
  - **MNIST/** — The MNIST dataset for handwritten digit recognition

- **Figure/** — Figures and illustrations organized from the book

- **Solutions/** — Mathematical derivations and solutions to exercises ⭐ Exercise solutions have been fully updated ⭐
  - Includes PDF materials covering probability theory, standard distributions, single-layer networks, Transformers, variational autoencoders, and other topics

## 📚 About the Book

*Deep Learning: Foundations and Concepts* is a comprehensive textbook introducing the theoretical foundations and central concepts of modern deep learning.

The book was written by Christopher M. Bishop and Hugh Bishop.

Christopher M. Bishop is a Microsoft Technical Fellow, Director of Microsoft Research AI4Science, Fellow of Darwin College, Cambridge, Fellow of the Royal Academy of Engineering, and Fellow of the Royal Society.

Hugh Bishop is an Applied Scientist at Wayve in London, where he works on deep neural networks for end-to-end autonomous driving.

### 🌟 Key Features

- Comprehensive coverage from foundational concepts to advanced deep learning architectures
- Clear explanations through text, figures, mathematical equations, and pseudocode
- A self-contained introduction to probability theory
- Detailed treatment of modern neural network architectures, including MLPs, CNNs, Transformers, and GNNs
- Coverage of attention mechanisms, GANs, latent-variable models, normalizing flows, autoencoders, and diffusion models
- A strong emphasis on the probabilistic foundations underlying modern machine learning
- Suitable for both systematic study and reference

### 🎯 Target Audience

- Beginners in machine learning and deep learning
- Experienced practitioners seeking a stronger theoretical foundation
- Undergraduate and graduate students
- Academic researchers
- Self-learners interested in the mathematical foundations of deep learning
- Professionals preparing for further specialization or research

## 📖 Recommended Prerequisites

- Basic linear algebra, including matrix operations and eigenvalues
- Basic probability theory, including conditional probability and Bayes' theorem
- Basic calculus, including gradients and partial derivatives

## 🛠️ How to Use This Repository

1. Start with the notebooks in the `Code/` directory to gain hands-on experience.
2. Attempt the exercises independently before consulting the derivations and solutions in `Solutions/`.
3. Use the datasets in `Data/` for practical implementations and experiments.
4. Refer to the figures in `Figure/` for additional visual explanations and intuition.
